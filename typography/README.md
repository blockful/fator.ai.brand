# Tipografia

As fontes da marca não são distribuídas neste repositório: a licença da Switzer
(Fontshare/ITF) não permite redistribuir os arquivos de fonte. Baixe dos links oficiais:

- [Switzer](https://www.fontshare.com/fonts/switzer): Regular 400 e Medium 500, tudo que se lê.
- [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk): Medium 500, etiquetas em caixa alta.
- [Gambarino](https://www.fontshare.com/fonts/gambarino): vive apenas dentro do logo.

Na web, carregue pelos links oficiais (ver [SKILL.md](../SKILL.md) §3). Para arquivos
que precisam funcionar offline, o CSS com as fontes embutidas em base64
(`fonts-embedded.css`) fica no repositório interno de skills do time, na skill
`fator-visual-id`.
